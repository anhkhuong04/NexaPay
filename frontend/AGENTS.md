# Frontend instructions

Follow root AGENTS.md. React/TypeScript/Vite, Fluent UI v9/Fluent System Icons.
Use semantic tokens, TanStack Query, React Hook Form/Zod and exact money strings.
Auth uses same-origin cookies/CSRF. Clear/cancel actor queries at auth transitions.
No invented transactions, working-looking future actions or optimistic money success.
From frontend: `npm ci`, `npm run dev`, `npm run build`, `npm run lint`,
`npm run test`, `npm run test:e2e`. E2E requires the real backend/database runtime.
Check semantic labels, keyboard/focus, errors, contrast and mobile layout when changed.
